# 第 19 章 算法库

算法库是 C++ 标准库的“大脑”部分，提供了对容器和范围进行查找、排序、变换、复制、删除等操作的通用算法。标准库算法的核心设计理念是：**算法与容器解耦，通过迭代器或范围操作数据**。这意味着同一个 `std::sort` 既能排 `std::vector`，也能排 `std::array` 或原生数组，只要它们提供合适的迭代器。

本章覆盖：

- 19.1 非修改序列算法与修改序列算法；
- 19.2 排序、二分查找与堆算法；
- 19.3 数值算法与并行执行策略；
- 19.4 受约束算法（C++20）。

核心原则依然是**选型而非 API 罗列**：手写循环 vs 标准算法、排序 vs 稳定排序、串行 vs 并行，每一节都会给出决策依据和反例。

> **工具约定**：示例以 C++20 为基线；并行执行策略（`std::execution::par`）是 C++17 特性，实际性能依赖编译器和运行时库支持；受约束算法是 C++20 特性。代码片段可用 `cxxsh` 单文件验证，放入真实项目时请套用第 7.7 节的 CMake + vcpkg 工程模板。

## 19.1 非修改序列算法与修改序列算法

### 19.1.1 算法的两大类

标准库算法大致分成两类：

- **非修改序列算法**：只读取元素，不改变容器内容，如 `find`、`count`、`accumulate`、`equal`；
- **修改序列算法**：会改变容器内容，如 `sort`、`copy`、`fill`、`replace`、`remove`。

所有算法都定义在 `<algorithm>` 头文件里（数值算法在 `<numeric>`）。它们通过迭代器范围 `[first, last)` 或 C++20 范围操作数据。

### 19.1.2 非修改序列算法示例

```cpp
// non_modifying_algorithms.cpp
// 需要 C++20
#include <iostream>
#include <vector>
#include <algorithm>
#include <ranges>

int main() {
    std::vector<int> v = {5, 2, 8, 1, 9, 3, 8, 4};

    // 查找第一个大于 5 的元素
    auto it = std::ranges::find_if(v, [](int x) { return x > 5; });
    if (it != v.end()) {
        std::cout << "第一个大于 5 的元素：" << *it << '\n';
    }

    // 统计等于 8 的元素个数
    auto cnt = std::ranges::count(v, 8);
    std::cout << "8 出现的次数：" << cnt << '\n';

    // 判断是否所有元素都大于 0
    bool all_pos = std::ranges::all_of(v, [](int x) { return x > 0; });
    std::cout << "所有元素都大于 0？ " << std::boolalpha << all_pos << '\n';

    // 查找最大元素
    auto max_it = std::ranges::max_element(v);
    std::cout << "最大元素：" << *max_it << '\n';
}
```

输出：

```
第一个大于 5 的元素：8
8 出现的次数：2
所有元素都大于 0？ true
最大元素：9
```

常用非修改算法：
- `find` / `find_if` / `find_if_not`：查找满足条件的第一个元素；
- `count` / `count_if`：统计满足条件的元素个数；
- `all_of` / `any_of` / `none_of`：判断所有/任意/无元素是否满足条件；
- `min_element` / `max_element`：查找最小/最大元素；
- `accumulate`（`<numeric>`）：累加求和（见 19.3）。

### 19.1.3 修改序列算法示例

```cpp
// modifying_algorithms.cpp
// 需要 C++20
#include <iostream>
#include <vector>
#include <algorithm>
#include <ranges>

int main() {
    std::vector<int> v = {3, 1, 4, 1, 5, 9, 2, 6};

    // 把所有 1 替换成 99
    std::ranges::replace(v, 1, 99);
    for (int x : v) std::cout << x << ' ';
    std::cout << '\n';

    // 把所有偶数变成 0
    std::ranges::replace_if(v, [](int x) { return x % 2 == 0; }, 0);
    for (int x : v) std::cout << x << ' ';
    std::cout << '\n';

    // 删除所有 99（“移除-擦除”惯用法的 C++20 新写法）
    std::ranges::erase(v, 99);
    for (int x : v) std::cout << x << ' ';
    std::cout << '\n';

    // 复制到另一个 vector
    std::vector<int> dst;
    std::ranges::copy(v, std::back_inserter(dst));
    for (int x : dst) std::cout << x << ' ';
    std::cout << '\n';
}
```

输出：

```
99 99 4 99 5 99 2 6 
99 99 4 99 5 99 0 6 
4 5 0 6 
4 5 0 6 
```

注意 C++20 新增的 `std::ranges::erase`，直接删掉容器里等于某值的所有元素，不再需要老式的 `v.erase(std::remove(v.begin(), v.end(), val), v.end())` “移除-擦除”惯用法。

### 19.1.4 标准算法 vs 手写循环

**选型口诀**：能用标准算法，就不要手写循环。

| 比较项 | 标准算法 | 手写循环 |
|---|---|---|
| 可读性 | 意图明确（一眼看出是“查找”“排序”“替换”） | 需要读完循环体才明白在做什么 |
| 正确性 | 经过标准委员会和社区长期验证 | 容易写出越界、条件错、迭代器失效等 bug |
| 性能 | 编译器可内联，优化空间大 | 与算法相当，但更容易写出次优代码 |
| 可维护性 | 标准命名，团队成员易理解 | 每人写法不同，维护成本高 |

**反例**：不要为了“展示控制流”而手写一个查找循环：

```cpp
// 不推荐：手写查找循环
bool found = false;
for (size_t i = 0; i < v.size(); ++i) {
    if (v[i] == target) {
        found = true;
        break;
    }
}

// 推荐：标准算法
bool found = std::ranges::contains(v, target);  // C++20
// 或
auto it = std::ranges::find(v, target);
bool found = (it != v.end());
```

> **小结**：非修改算法只读取元素（`find`、`count`、`all_of` 等），修改算法会改变容器（`replace`、`erase`、`copy` 等）；C++20 的 `std::ranges::erase` 简化了“移除-擦除”惯用法；优先使用标准算法，避免手写循环。

## 19.2 排序、二分查找与堆算法

### 19.2.1 排序算法

| 算法 | 头文件 | 稳定性 | 复杂度 | 适用场景 |
|---|---|---|---|---|
| `std::sort` | `<algorithm>` | 不稳定 | O(n log n) | 通用排序，最快 |
| `std::stable_sort` | `<algorithm>` | 稳定 | O(n log n)，内存足够时；O(n log² n) 否则 | 需要保持相等元素相对顺序 |
| `std::partial_sort` | `<algorithm>` | 不稳定 | O(n log k) | 只需要前 k 小/大的元素 |
| `std::ranges::sort` | `<algorithm>` | 不稳定 | O(n log n) | C++20 范围版本 |

```cpp
// sort_algorithms.cpp
// 需要 C++20
#include <iostream>
#include <vector>
#include <algorithm>
#include <ranges>

int main() {
    std::vector<int> v = {5, 2, 8, 1, 9, 3};

    std::ranges::sort(v);  // 升序
    for (int x : v) std::cout << x << ' ';
    std::cout << '\n';

    std::ranges::sort(v, std::greater{});  // 降序
    for (int x : v) std::cout << x << ' ';
    std::cout << '\n';
}
```

输出：

```
1 2 3 5 8 9 
9 8 5 3 2 1 
```

### 19.2.2 二分查找

二分查找要求**序列已经有序**。标准库提供：

- `std::binary_search`：判断是否存在某值；
- `std::lower_bound`：第一个不小于值的元素；
- `std::upper_bound`：第一个大于值的元素；
- `std::equal_range`：等于值的元素范围。

```cpp
// binary_search_algorithms.cpp
// 需要 C++20
#include <iostream>
#include <vector>
#include <algorithm>
#include <ranges>

int main() {
    std::vector<int> v = {1, 3, 5, 7, 9, 11};
    std::ranges::sort(v);  // 确保有序

    std::cout << "是否包含 7？ " << std::ranges::binary_search(v, 7) << '\n';
    std::cout << "是否包含 6？ " << std::ranges::binary_search(v, 6) << '\n';

    auto lb = std::ranges::lower_bound(v, 7);  // 第一个 >= 7
    std::cout << "lower_bound(7) 指向：" << (lb != v.end() ? std::to_string(*lb) : "end") << '\n';

    auto ub = std::ranges::upper_bound(v, 7);  // 第一个 > 7
    std::cout << "upper_bound(7) 指向：" << (ub != v.end() ? std::to_string(*ub) : "end") << '\n';
}
```

输出：

```
是否包含 7？ true
是否包含 6？ false
lower_bound(7) 指向：7
upper_bound(7) 指向：9
```

**反例**：不要在无序序列上用二分查找，结果是未定义行为或错误答案。二分查找前必须先 `sort`。

### 19.2.3 堆算法

堆（heap）是一种部分有序的数据结构，堆顶始终是最大元素（默认）。标准库堆算法：

- `std::make_heap`：把范围变成堆；
- `std::push_heap`：向堆中压入新元素；
- `std::pop_heap`：把堆顶元素移到末尾（配合 `pop_back` 实现弹出）；
- `std::sort_heap`：把堆排序。

```cpp
// heap_algorithms.cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> v = {3, 1, 4, 1, 5, 9, 2, 6};

    std::make_heap(v.begin(), v.end());
    std::cout << "堆顶（最大值）：" << v.front() << '\n';  // 9

    std::pop_heap(v.begin(), v.end());  // 最大值移到末尾
    std::cout << "弹出堆顶：" << v.back() << '\n';
    v.pop_back();

    std::cout << "新堆顶：" << v.front() << '\n';  // 6
}
```

输出：

```
堆顶（最大值）：9
弹出堆顶：9
新堆顶：6
```

如果你需要优先级队列，直接用 `std::priority_queue`（第 9 章讲过）即可，不需要手动操作堆算法。堆算法更适合“原地把一段内存变成堆”这种底层场景。

### 19.2.4 排序算法选型

| 需求 | 推荐 | 原因 |
|---|---|---|
| 普通排序，不关心相等元素顺序 | `std::ranges::sort` | 最快 |
| 需要保持相等元素原相对顺序 | `std::ranges::stable_sort` | 稳定排序 |
| 只需要前 k 个最小/最大 | `std::ranges::partial_sort` | 避免全排序开销 |
| 需要频繁取最大/最小元素 | `std::priority_queue` | 专门的适配器，不用手动维护堆 |

## 19.3 数值算法与并行执行策略

### 19.3.1 数值算法

数值算法定义在 `<numeric>`，用于对序列做数值运算：

| 算法 | 作用 |
|---|---|
| `std::accumulate` | 累加（或累积其他二元运算） |
| `std::reduce` | 并行友好的累加，不保证顺序（C++17） |
| `std::transform_reduce` | 先变换再归约（C++17） |
| `std::inner_product` | 内积 / 累积组合 |
| `std::adjacent_difference` | 相邻元素差值 |
| `std::partial_sum` | 前缀和 |

```cpp
// numeric_algorithms.cpp
#include <iostream>
#include <vector>
#include <numeric>

int main() {
    std::vector<int> v = {1, 2, 3, 4, 5};

    // 求和
    int sum = std::accumulate(v.begin(), v.end(), 0);
    std::cout << "sum = " << sum << '\n';  // 15

    // 累乘
    int product = std::accumulate(v.begin(), v.end(), 1, std::multiplies<int>{});
    std::cout << "product = " << product << '\n';  // 120

    // 前缀和
    std::vector<int> prefix(v.size());
    std::partial_sum(v.begin(), v.end(), prefix.begin());
    for (int x : prefix) std::cout << x << ' ';
    std::cout << '\n';  // 1 3 6 10 15
}
```

输出：

```
sum = 15
product = 120
1 3 6 10 15 
```

### 19.3.2 并行执行策略（C++17）

C++17 为部分标准库算法引入了**执行策略（execution policy）**，允许你 hint 算法可以并行执行。定义在 `<execution>`：

- `std::execution::seq`：串行执行（默认）；
- `std::execution::par`：并行执行；
- `std::execution::par_unseq`：并行 + 向量化，可能重排顺序。

```cpp
// parallel_algorithm.cpp
// 需要 C++17，并行执行依赖编译器和运行时库支持（如 GCC 需链接 TBB）
#include <iostream>
#include <vector>
#include <algorithm>
#include <execution>
#include <numeric>

int main() {
    std::vector<int> v(1000000);
    std::iota(v.begin(), v.end(), 1);

    // 串行累加
    long long sum_seq = std::accumulate(v.begin(), v.end(), 0LL);

    // 并行归约（结果不保证顺序，但对加法来说顺序不影响正确性）
    long long sum_par = std::reduce(std::execution::par, v.begin(), v.end(), 0LL);

    std::cout << "stSerial sum = " << sum_seq << '\n';
    std::cout << "parallel sum = " << sum_par << '\n';
}
```

并行算法的注意事项：
1. **不是所有算法都支持并行策略**，只有标准库明确标注的才支持（如 `sort`、`copy`、`fill`、`reduce`、`transform_reduce` 等）；
2. **并行不一定更快**：小数据量下，线程调度开销可能超过计算本身；
3. **并行算法对用户提供的函数对象有要求**：必须是线程安全的，不能有数据竞争。例如并行 `sort` 的比较函数必须是纯函数，不能修改外部状态；
4. `std::reduce` 不保证归约顺序，因此只适用于结合律满足的运算（如整数加法、浮点加法注意精度损失）；如果必须保证顺序，用 `std::accumulate`。

> **小结**：`std::accumulate` 做顺序累加，`std::reduce` 适合并行归约但不保证顺序；`std::transform_reduce` 先变换再归约；并行执行策略（`std::execution::par`）可让支持的算法多线程运行，但小数据量和非线程安全的操作不适合并行。

## 19.4 受约束算法（C++20）

### 19.4.1 什么是受约束算法

C++20 的范围库不仅给算法换了名字空间（`std::ranges`），还给很多算法加上了**概念约束（constraints）**。受约束算法会在编译期检查迭代器/范围是否满足所需概念，如果不满足，编译器会给出清晰的错误信息，而不是几十行模板实例化堆栈。

例如 `std::ranges::sort` 要求迭代器是随机访问迭代器，且元素可比较。如果你传一个 `std::list`（双向迭代器，不是随机访问），编译会直接失败并指出问题。

```cpp
// constrained_algorithm.cpp
// 需要 C++20
#include <iostream>
#include <list>
#include <algorithm>
#include <ranges>

int main() {
    std::list<int> lst = {3, 1, 2};
    // std::ranges::sort(lst.begin(), lst.end());  // 编译错误！list 迭代器不是随机访问
    std::cout << "list 不能直接用 ranges::sort\n";
}
```

### 19.4.2 受约束算法的好处

1. **错误信息清晰**：传统 `std::sort` 接收两个模板迭代器参数，如果传错类型，错误信息会在模板实例化深处才爆炸；受约束算法会在入口处就检查概念，错误信息直接指向“不满足 random_access_iterator”。
2. **避免迭代器类型不匹配**：传统算法要求 `begin` 和 `end` 类型完全相同；受约束范围算法允许 `begin` 和 `end` 是哨兵（sentinel）类型（见第 17 章），更灵活。
3. **投影支持**：受约束算法普遍支持投影参数，无需自定义比较器。

### 19.4.3 选型建议

| 场景 | 推荐 |
|---|---|
| C++20 环境，新代码 | `std::ranges::xxx`（受约束算法） |
| C++17 及以下，或需要和旧代码兼容 | `std::xxx`（传统算法） |
| 需要并行执行 | 传统算法 + `std::execution::par`（受约束算法并行支持因编译器而异） |

## 本章小结

本章我们学习了标准库算法设施的核心内容：

1. **非修改序列算法**：`find`、`count`、`all_of`、`min_element`/`max_element` 等，只读取元素不改变容器；
2. **修改序列算法**：`replace`、`replace_if`、`erase`、`copy` 等，会改变容器内容；C++20 的 `std::ranges::erase` 简化了“移除-擦除”惯用法；
3. **排序与二分查找**：`sort`/`stable_sort`/`partial_sort` 排序；`binary_search`/`lower_bound`/`upper_bound` 二分查找（要求先有序）；堆算法 `make_heap`/`push_heap`/`pop_heap`；
4. **数值算法**：`accumulate` 顺序累加，`reduce`/`transform_reduce` 并行友好归约，`partial_sum` 前缀和；
5. **并行执行策略**：`std::execution::par`/`par_unseq` 让支持的算法多线程运行，但要注意数据量和线程安全；
6. **受约束算法（C++20）**：`std::ranges` 算法基于概念约束，错误信息清晰，支持投影和哨兵范围。

选型口诀：**能用标准算法就别手写循环；普通排序用 `sort`，保持相对顺序用 `stable_sort`；先有序再二分查找；求和小数据用 `accumulate`，大数据并行用 `reduce`；C++20 优先 `std::ranges` 版本。**

5. 故意把 `std::list` 传给 `std::ranges::sort`，观察编译器的概念错误信息。
