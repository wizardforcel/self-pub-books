# 第 28 章 Boost 测试、序列化与工程设施

Boost 除了容器、字符串、并发和数值设施外，还提供了一组面向工程实践的库：单元测试框架、对象序列化、图算法。这些设施在实际项目中直接关系到“代码怎么测、怎么持久化、怎么处理图结构数据”。

本章覆盖：

- 28.1 `boost::test`：单元测试框架；
- 28.2 `boost::serialization`：对象序列化；
- 28.3 `boost::graph`（BGL）：通用图算法与数据结构。

每一节都会标注该设施的定位：**已被标准化 / 部分标准化 / 纯 Boost 独有**。

> **工具约定**：示例默认采用 CMake + vcpkg 工程模板，Boost 依赖通过 vcpkg 清单引入。Boost.Test 有 header-only 和 compiled 两种用法，Boost.Serialization 通常需要链接 `boost::serialization`，Boost.Graph 是 header-only。代码片段可用 `cxxsh` 单文件验证，放入真实项目时请套用第 7.7 节的工程模板。

## 28.1 `boost::test`：单元测试框架

### 28.1.1 什么是 Boost.Test

`boost::test`（Boost.Test，`<boost/test/unit_test.hpp>`）是 Boost 的单元测试框架，提供测试用例、测试套件、断言宏、测试主程序自动生成等功能。它与 GoogleTest、Catch2 类似，但历史更悠久，且与 Boost 库本身集成紧密。

定位：**纯 Boost 独有**（标准库没有内置单元测试框架；项目通常根据偏好选用 GoogleTest、Catch2 或 Boost.Test）。

### 28.1.2 基本用法

Boost.Test 最简单的用法是定义一个测试主程序，然后写测试用例和断言：

```cpp
// boost_test_basic.cpp
// Boost.Test header-only：定义 BOOST_TEST_MODULE 后包含头文件
#define BOOST_TEST_MODULE MyTest
#include <boost/test/unit_test.hpp>

BOOST_AUTO_TEST_CASE(test_addition) {
    int a = 2, b = 3;
    BOOST_TEST(a + b == 5);
    BOOST_TEST(a * b == 6);
}

BOOST_AUTO_TEST_CASE(test_string) {
    std::string s = "hello";
    BOOST_TEST(s.size() == 5);
    BOOST_TEST(!s.empty());
}
```

编译运行（需要链接 `boost::unit_test_framework`，除非使用 header-only 的自动注册模式，具体取决于 Boost 版本和编译选项）：

```
Running 2 test cases...
MyTest.cpp(6): error: in "test_addition": condition a * b == 6 failed
...
```

常用断言宏：
- `BOOST_TEST(condition)`：基本断言，条件为假时记录失败但继续；
- `BOOST_REQUIRE(condition)`：强制断言，条件为假时立即终止当前测试用例；
- `BOOST_TEST_EQ(a, b)`、`BOOST_TEST_NE(a, b)`、`BOOST_TEST_LT(a, b)` 等：带类型信息的比较断言；
- `BOOST_TEST_THROWS(expr, exception_type)`：断言表达式抛出指定异常；
- `BOOST_TEST_CLOSE(a, b, tolerance)`：断言两个浮点数在容差范围内相等。

### 28.1.3 与 GoogleTest / Catch2 的对比

| 特性 | Boost.Test | GoogleTest | Catch2 |
|---|---|---|---|
| 头文件/编译模式 | 支持 header-only 和 compiled | 主要 compiled | 主要 header-only |
| 断言风格 | `BOOST_TEST` 宏 | `EXPECT_*` / `ASSERT_*` 宏 | `REQUIRE` / `CHECK` 宏 |
| 测试发现 | 自动注册（基于宏） | 自动注册 | 自动注册 |
| 与 Boost 集成 | 紧密 | 独立 | 独立 |
| 流行度 | 中（Boost 项目常用） | 高 | 高（现代 C++ 项目常选） |

选型建议：新项目中，GoogleTest 和 Catch2 的社区生态和文档更丰富，通常作为首选；Boost.Test 适合已经大量使用 Boost、或者希望测试框架与 Boost 库保持一致风格的项目。

## 28.2 `boost::serialization`：对象序列化

### 28.2.1 什么是序列化

序列化（serialization）是指把内存中的对象状态转换为可存储或传输的格式（文本、XML、二进制），并在需要时重建对象。常见用途：保存游戏存档、缓存配置、网络传输数据、进程间通信。

`boost::serialization`（`<boost/serialization/serialization.hpp>` 等）是 Boost 的序列化库，支持通过成员函数 `serialize` 或自由函数将对象持久化为多种归档格式，并自动处理指针、引用、容器、版本控制等。

定位：**纯 Boost 独有**（标准库没有对象序列化设施；C++ 标准没有反射，无法在标准层面实现通用序列化）。

### 28.2.2 基本用法：文本归档

```cpp
// boost_serialization_basic.cpp
// Boost.Serialization 通常需要链接 boost::serialization
#include <iostream>
#include <fstream>
#include <string>
#include <boost/serialization/serialization.hpp>
#include <boost/serialization/string.hpp>
#include <boost/archive/text_oarchive.hpp>
#include <boost/archive/text_iarchive.hpp>

class Person {
    friend class boost::serialization::access;

    std::string name;
    int age;

    template <class Archive>
    void serialize(Archive& ar, const unsigned int version) {
        ar & name & age;  // 同时支持保存和加载
    }

public:
    Person() = default;
    Person(std::string n, int a) : name(std::move(n)), age(a) {}
    std::string get_name() const { return name; }
    int get_age() const { return age; }
};

int main() {
    // 序列化到文件
    {
        Person p("张三", 25);
        std::ofstream ofs("person.txt");
        boost::archive::text_oarchive oa(ofs);
        oa << p;   // 保存
    }

    // 反序列化从文件
    {
        Person p;
        std::ifstream ifs("person.txt");
        boost::archive::text_iarchive ia(ifs);
        ia >> p;   // 加载
        std::cout << "姓名：" << p.get_name() << ", 年龄：" << p.get_age() << "\n";
    }
}
```

可能的输出：

```
姓名：张三，年龄：25
```

`person.txt` 的内容大致是：

```
0 serialization::archive 12 0 0 0
张三
25
```

### 28.2.3 关键特性

- **多种归档格式**：`text_oarchive`/`text_iarchive`（文本）、`xml_oarchive`/`xml_iarchive`（XML）、`binary_oarchive`/`binary_iarchive`（二进制）；
- **指针与引用跟踪**：序列化时自动处理对象图中的共享指针和循环引用，避免重复保存或无限递归；
- **版本控制**：`serialize` 函数可以接收版本号，支持旧数据与新类结构的兼容加载；
- **STL 容器支持**：`std::vector`、`std::map`、`std::string` 等标准容器开箱即用支持序列化。

使用时要注意：被序列化的类需要提供 `serialize` 成员函数（或自由函数），并声明 `boost::serialization::access` 为友元；基类和派生类的序列化需要显式注册（`BOOST_CLASS_EXPORT`）。

## 28.3 `boost::graph`（BGL）：通用图算法与数据结构

### 28.3.1 什么是 BGL

`boost::graph`（Boost Graph Library, BGL，`<boost/graph/adjacency_list.hpp>` 等）是 Boost 的通用图算法库，提供了图的表示（`adjacency_list` 邻接表、`adjacency_matrix` 邻接矩阵等）和大量图算法（BFS、DFS、最短路径、最小生成树、拓扑排序、强连通分量等）。

BGL 的设计核心是**泛型**：图的表示和算法通过概念解耦，同一套算法可以作用于多种图结构（只要满足对应的图概念）。它还提供 **visitor 机制**，让用户在算法遍历过程中的特定节点（如“发现顶点”“检查边”）注入自定义逻辑。

定位：**纯 Boost 独有**（标准库没有图数据结构和图算法）。

### 28.3.2 基本用法：构建图并做 BFS

```cpp
// boost_graph_basic.cpp
// Boost.Graph 是 header-only，无需链接库文件
#include <iostream>
#include <boost/graph/adjacency_list.hpp>
#include <boost/graph/breadth_first_search.hpp>

using namespace boost;

int main() {
    // 定义有向图：邻接表，顶点属性和边属性都用无属性（no_property）
    using Graph = adjacency_list<vecS, vecS, directedS>;
    Graph g(6);  // 6 个顶点，编号 0-5

    // 添加边
    add_edge(0, 1, g);
    add_edge(0, 2, g);
    add_edge(1, 3, g);
    add_edge(1, 4, g);
    add_edge(2, 5, g);

    // 广度优先搜索，从顶点 0 开始
    std::cout << "BFS 从顶点 0 开始：";
    breadth_first_search(g, vertex(0, g),
        visitor(make_bfs_visitor(
            on_tree_edge([](auto e, auto& g) {
                std::cout << "(" << source(e, g) << "->" << target(e, g) << ") ";
            })
        ))
    );
    std::cout << "\n";
}
```

可能的输出：

```
BFS 从顶点 0 开始：(0->1) (0->2) (1->3) (1->4) (2->5) 
```

### 28.3.3 选型建议

| 需求 | 推荐 | 原因 |
|---|---|---|
| 单元测试框架 | GoogleTest / Catch2 / Boost.Test | 标准库无测试框架，按团队偏好选 |
| 对象序列化 | `boost::serialization` | 标准库无序列化，Boost 独有 |
| 图数据结构与算法 | `boost::graph` (BGL) | 标准库无图库，Boost 独有 |

## 本章小结

本章我们学习了 Boost 测试、序列化与工程设施：

1. **`boost::test`**：纯 Boost 独有，单元测试框架，提供 `BOOST_TEST`/`BOOST_REQUIRE` 等断言宏；新项目可根据偏好选 GoogleTest、Catch2 或 Boost.Test；
2. **`boost::serialization`**：纯 Boost 独有，对象序列化，支持文本/XML/二进制归档、指针引用跟踪、版本控制；
3. **`boost::graph` (BGL)**：纯 Boost 独有，通用图库，提供邻接表/矩阵图表示、BFS/DFS、最短路径、最小生成树等算法，支持 visitor 机制。

选型口诀：**单元测试按团队偏好选框架；对象持久化用 `boost::serialization`；图结构与图算法用 `boost::graph`；以上均为 Boost 独有，标准库无对应。**
