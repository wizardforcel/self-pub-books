# 第 24 章 Boost 字符串、文本与解析

标准库的字符串设施（`std::string`、`std::string_view`、`std::regex`、`std::format`）已经能覆盖大部分日常文本处理需求。但在某些场景下，标准库仍显不足：需要更丰富的字符串算法（裁剪、分割、连接、大小写转换）、需要在尚未升级到 C++20 的项目中用类型安全的格式化、需要把文本拆分成 token、或者需要直接在 C++ 里写解析器生成复杂语法树。Boost 的字符串与解析库正是为此而生。

本章覆盖：

- 24.1 `boost::algorithm` 与字符串算法扩展；
- 24.2 `boost::format`：类型安全的格式化；
- 24.3 `boost::tokenizer` 与文本分词；
- 24.4 `boost::spirit`：基于表达式模板的解析器生成。

每一节都会标注该设施的定位：**已被标准化 / 部分标准化 / 纯 Boost 独有**。

> **工具约定**：示例默认采用 CMake + vcpkg 工程模板，Boost 依赖通过 vcpkg 清单引入。Boost.StringAlgo、Boost.Format、Boost.Tokenizer 大多是 header-only，Boost.Spirit 也是 header-only。代码片段可用 `cxxsh` 单文件验证，放入真实项目时请套用第 7.7 节的工程模板。

## 24.1 `boost::algorithm` 与字符串算法扩展

### 24.1.1 标准库字符串算法的空白

标准库 `<algorithm>` 和 `<string>` 提供了一些基础字符串操作（如 `find`、`substr`、`compare`，C++20 起有 `starts_with`/`ends_with`/`contains`），但缺少一批日常文本处理中很常用的算法，例如：

- 修剪空白（trim left/right/both）；
- 分割字符串（split）；
- 拼接容器（join）；
- 大小写转换（to_upper/to_lower）；
- 判断是否以某子串开头/结尾（C++20 前标准库没有）。

Boost.StringAlgo（`boost::algorithm::string`）填补了这些空白，提供了一组以 `boost::algorithm` 命名空间下的自由函数，操作对象通常是 `std::string` 或 `std::string_view`。

定位：**部分标准化**（C++20 的 `starts_with`/`ends_with`/`contains` 部分重叠，但 Boost 覆盖更全面；标准库没有 trim/split/join）。

### 24.1.2 基本用法

```cpp
// boost_algorithm_basic.cpp
// Boost.StringAlgo 是 header-only，无需链接库文件
#include <iostream>
#include <string>
#include <vector>
#include <boost/algorithm/string.hpp>

int main() {
    using namespace boost::algorithm;

    std::string s = "  Hello, World!  ";

    // 修剪空白（返回新字符串，不修改原串）
    std::string trimmed = trim_copy(s);
    std::cout << "trim: [" << trimmed << "]\n";

    // 原地修剪
    std::string s2 = s;
    trim(s2);
    std::cout << "trim in place: [" << s2 << "]\n";

    // 大小写转换
    std::string upper = to_upper_copy("Hello");
    std::string lower = to_lower_copy("HELLO");
    std::cout << "upper: " << upper << ", lower: " << lower << "\n";

    // 分割
    std::vector<std::string> parts;
    split(parts, "a,b,c", is_any_of(","));
    std::cout << "split: ";
    for (const auto& p : parts) {
        std::cout << "[" << p << "] ";
    }
    std::cout << "\n";

    // 拼接容器
    std::vector<std::string> v = {"apple", "banana", "cherry"};
    std::string joined = join(v, ", ");
    std::cout << "join: " << joined << "\n";

    // 判断开头/结尾（C++20 标准库也有 starts_with/ends_with，Boost 更早提供）
    std::cout << "starts_with Hello: " << starts_with(s, "  He") << "\n";
    std::cout << "ends_with World!: " << ends_with(s, "rld!  ") << "\n";
}
```

输出：

```
trim: [Hello, World!]
trim in place: [Hello, World!]
upper: HELLO, lower: hello
split: [a] [b] [c] 
join: apple, banana, cherry
starts_with Hello: 1, ends_with World!: 1
```

注意：`trim`、`to_upper` 等有“带 `_c` 后缀”和“不带后缀”两个版本：
- 不带后缀（如 `trim`）：原地修改传入的字符串；
- 带 `_c` 后缀（如 `trim_copy`）：返回修改后的副本，原串不变。

### 24.1.3 常用算法速查

| 算法 | 作用 | 标准库对应 |
|---|---|---|
| `trim` / `trim_copy` | 修剪两端空白 | C++20 无直接对应 |
| `trim_left` / `trim_right` | 只修剪左/右端 | C++20 无直接对应 |
| `to_upper` / `to_upper_copy` | 转大写 | C++20 无直接对应 |
| `to_lower` / `to_lower_copy` | 转小写 | C++20 无直接对应 |
| `split` | 按分隔符或谓词分割 | C++20 无直接对应 |
| `join` | 把容器元素拼成字符串 | C++20 无直接对应 |
| `starts_with` / `ends_with` | 判断前缀/后缀 | C++20 `std::string::starts_with/ends_with` |
| `contains` | 判断是否包含子串 | C++20 `std::string::contains` |

### 24.1.4 选型建议

| 需求 | 推荐 | 原因 |
|---|---|---|
| 修剪、分割、拼接、大小写转换 | `boost::algorithm` | 标准库缺失这些算法，Boost 最成熟 |
| 只判断前缀/后缀/包含，且已用 C++20 | `std::string::starts_with/ends_with/contains` | 标准库，无需引入 Boost |
| 复杂文本解析 | `boost::tokenizer` 或 `boost::spirit` | 见 24.3、24.4 |

## 24.2 `boost::format`：类型安全的格式化

### 24.2.1 为什么需要 `boost::format`

C 风格 `printf` / `sprintf` 格式化简洁，但类型不安全：格式字符串里的 `%d` 传了 `double`，行为未定义；缓冲区溢出风险高。C++ `std::cout <<` 类型安全，但语法啰嗦，不方便写“模板化”的格式字符串。

`boost::format`（`<boost/format.hpp>`）提供了一种类型安全的、类 `printf` 风格的格式化方式，用 `%1%`、`%2%` 等占位符引用参数，支持类型推导和自定义格式。

定位：**部分标准化**（C++20 `std::format` 是标准库的类型安全格式化，`boost::format` 是其前身和替代；若项目已用 C++20，优先 `std::format`）。

### 24.2.2 基本用法

```cpp
// boost_format_basic.cpp
// Boost.Format 是 header-only，无需链接库文件
#include <iostream>
#include <string>
#include <boost/format.hpp>

int main() {
    using namespace boost;

    std::string name = "张三";
    int age = 25;
    double score = 89.567;

    // %1%、%2%、%3% 引用第 1、2、3 个参数
    std::string result = (format("姓名：%1%，年龄：%2%，成绩：%3%") % name % age % score).str();
    std::cout << result << '\n';

    // 可以指定精度
    std::string result2 = (format("成绩：%.2f") % score).str();
    std::cout << result2 << '\n';

    // 占位符可重复使用，顺序可调整
    std::string result3 = (format("%2% 年龄 %1% 岁") % age % name).str();
    std::cout << result3 << '\n';
}
```

输出：

```
姓名：张三，年龄：25，成绩：89.567
成绩：89.57
25 年龄 张三 岁
```

`boost::format` 返回一个 `format` 对象，用 `%` 运算符依次绑定参数，最后调用 `.str()` 得到 `std::string`，也可直接流式输出到 `std::cout`。

### 24.2.3 与 `std::format` 的对比

| 特性 | `boost::format` | `std::format`（C++20） |
|---|---|---|
| 占位符语法 | `%1%`、`%2%` | `{}` |
| 类型安全 | 是 | 是 |
| 头文件 | `<boost/format.hpp>` | `<format>` |
| 是否需链接库 | 否（header-only） | 否（但需较新标准库）|
| 自定义类型格式化 | 需重载 `operator<<` 或特化 | 特化 `std::formatter` |
| 占位符重复/重排序 | 支持（`%1%` 可多次出现）| 支持（`{0}` `{1}`） |

如果项目已经升级到 C++20 且标准库支持 `<format>`，优先用 `std::format`；如果项目还在 C++11/14，且需要类型安全的格式化，`boost::format` 是很好的替代。

## 24.3 `boost::tokenizer` 与文本分词

### 24.3.1 什么是 tokenizer

文本分词（tokenization）是指把一段字符串按一定规则拆分成若干个“词元（token）”。例如把一行 CSV 拆成字段，把一句英文拆成单词，把一行命令拆成参数。

`boost::tokenizer`（`<boost/tokenizer.hpp>`）提供了一种基于迭代器的轻量分词方式：你给它一个字符串和一个分隔规则（如 `boost::char_separator<char>`），它产生一对迭代器，遍历即可得到每个 token。

定位：**纯 Boost 独有**（标准库没有直接的分词器，C++20 `std::views::split` 可部分替代，但 API 不同）。

### 24.3.2 基本用法

```cpp
// boost_tokenizer_basic.cpp
// Boost.Tokenizer 是 header-only，无需链接库文件
#include <iostream>
#include <string>
#include <boost/tokenizer.hpp>

int main() {
    using namespace boost;

    std::string csv = "张三,25,北京,工程师";
    tokenizer<escaped_list_separator<char>> tok(csv);
    for (const auto& t : tok) {
        std::cout << "[" << t << "]\n";
    }

    std::cout << "---\n";

    // 自定义分隔符：按空格和逗号分割
    std::string text = "apple, banana cherry";
    char_separator<char> sep(", ");
    tokenizer<char_separator<char>> tok2(text, sep);
    for (const auto& t : tok2) {
        std::cout << "[" << t << "]\n";
    }
}
```

输出：

```
[张三]
[25]
[北京]
[工程师]
---
[apple]
[ banana]
[cherry]
```

注意第二个例子中，`char_separator<char> sep(", ")` 把逗号和空格都当作分隔符，所以 `" banana"` 前面保留了一个空格。如果想把连续分隔符当作一个，或者要更精细的控制，可以调整 `char_separator` 的构造参数。

### 24.3.3 与标准库的对比

| 特性 | `boost::tokenizer` | C++20 `std::views::split` |
|---|---|---|
| 接口风格 | 迭代器对，范围 for 可用 | 视图，管道风格 |
| 分隔规则 | `char_separator`、`escaped_list_separator` 等 | 需要自定义 `std::views::split` 的分隔子视图 |
| 转义处理 | `escaped_list_separator` 支持 CSV 风格转义 | 需要手写 |
| 标准化 | 纯 Boost | 标准库 |

如果项目已用 C++20，简单的按字符分割可以用 `std::views::split`；需要 CSV 风格转义处理或更复杂分隔规则时，`boost::tokenizer` 更方便。

## 24.4 `boost::spirit`：基于表达式模板的解析器生成

### 24.4.1 什么是 Spirit

`boost::spirit` 是 Boost 的解析器生成框架，核心思想是**在 C++ 代码里直接写接近 EBNF（扩展巴科斯范式）的语法规则**，编译器通过表达式模板把这些规则展开成一个解析器。最常用的子库是 **Spirit.Qi**（用于解析，输入 → 结构化数据）和 **Spirit.Karma**（用于生成，结构化数据 → 输出）。

Spirit 不需要预处理步骤（不像 yacc/bison 需要先生成 `.c`/`.h` 文件），所有解析器都在 C++ 编译期由模板构建，头文件直接包含即用。

定位：**纯 Boost 独有**（标准库没有解析器生成器，C++23 也无相关标准化计划）。

### 24.4.2 基本用法：解析“整数,整数”

下面是一个最小的 Spirit.Qi 示例，解析形如 `"123,456"` 的输入，得到两个整数：

```cpp
// spirit_qi_basic.cpp
// Boost.Spirit 是 header-only，无需链接库文件
#include <iostream>
#include <string>
#include <boost/spirit/include/qi.hpp>

namespace qi = boost::spirit::qi;

int main() {
    std::string input = "123,456";
    int a = 0, b = 0;

    auto iter = input.begin();
    auto end = input.end();

    bool r = qi::parse(iter, end,
        qi::int_ >> ',' >> qi::int_,   // 语法规则：整数，逗号，整数
        a, b);                          // 绑定的输出变量

    if (r && iter == end) {
        std::cout << "解析成功：a=" << a << ", b=" << b << '\n';
    } else {
        std::cout << "解析失败或未完全消耗输入\n";
    }
}
```

输出：

```
解析成功：a=123, b=456
```

`qi::int_` 是一个预定义的解析器，匹配一个整数；`>>` 是序列操作符，表示“先匹配左边，再匹配右边”。`qi::parse` 返回是否匹配成功，并通过 `iter == end` 判断是否消耗了全部输入。

### 24.4.3 稍复杂的例子：解析键值对

```cpp
// spirit_kv_basic.cpp
#include <iostream>
#include <string>
#include <map>
#include <boost/spirit/include/qi.hpp>

namespace qi = boost::spirit::qi;
namespace ascii = boost::spirit::ascii;

int main() {
    std::string input = "name=张三,age=25,city=北京";
    std::map<std::string, std::string> kv;

    auto iter = input.begin();
    auto end = input.end();

    bool r = qi::parse(iter, end,
        // 规则：键值对，逗号分隔
        +(qi::lexeme[+ascii::alnum] >> '=' >> +qi::char_ - ',') % ',',
        kv);

    if (r && iter == end) {
        for (const auto& [k, v] : kv) {
            std::cout << k << " = " << v << '\n';
        }
    } else {
        std::cout << "解析失败\n";
    }
}
```

注意：这个示例比较简化，实际 `qi::parse` 绑定到 `std::map` 需要更精确的语义动作（`boost::phoenix` 或直接写 `on_success` 回调）。Spirit 的学习曲线较陡，初学者建议先从简单的 `qi::int_`、`qi::double_`、`qi::string` 等预定义解析器入手。

### 24.4.4 选型与学习建议

| 需求 | 推荐 | 原因 |
|---|---|---|
| 简单正则匹配 | `std::regex` | 标准库，够用 |
| 结构化文本解析（CSV、JSON 子集、自定义协议） | `boost::spirit` | 在 C++ 里直接写语法规则，无需预处理工具 |
| 复杂语言前端（编程语言、查询语言） | `boost::spirit` 或专用解析生成器（ANTLR、Tree-sitter）| Spirit 适合中等复杂度，极复杂语言可能需要专用工具 |

**反例**：不要为了“解析一个逗号分隔的字符串”就上 `boost::spirit`，`boost::tokenizer` 或 `std::views::split` 更简单；Spirit 适合“有递归结构、有运算符优先级、需要生成 AST”的解析场景。

## 本章小结

本章我们学习了 Boost 字符串、文本与解析设施：

1. **`boost::algorithm`**：部分标准化，提供 `trim`、`split`、`join`、`to_upper`/`to_lower` 等标准库缺失的字符串算法；
2. **`boost::format`**：部分标准化，类型安全的 `printf` 风格格式化，C++20 项目优先 `std::format`；
3. **`boost::tokenizer`**：纯 Boost 独有，基于迭代器的文本分词，支持 `escaped_list_separator` 等 CSV 风格分隔；
4. **`boost::spirit`**：纯 Boost 独有，基于表达式模板的解析器生成，Spirit.Qi 用于解析，Spirit.Karma 用于生成，适合结构化文本解析。

选型口诀：**字符串裁剪分割拼接用 `boost::algorithm`；类型安全格式化且已 C++20 用 `std::format`，否则用 `boost::format`；简单分词用 `std::views::split` 或 `boost::tokenizer`；结构化文本解析用 `boost::spirit`。**

下一章（第 25 章）我们进入 Boost 并发与网络，重点学习 `boost::asio` 的异步 I/O 模型，以及 `boost::thread`、`boost::coroutine2`、`boost::fibers`。

## 练习

1. 用 `boost::algorithm::trim_copy` 和 `boost::algorithm::split` 处理字符串 `"  apple, banana, cherry  "`，先修剪空白，再按逗号分割，打印每个 token。
2. 用 `boost::format` 构造一条格式化日志字符串，包含时间戳、日志级别和消息，打印结果。
3. 用 `boost::tokenizer` 与 `boost::escaped_list_separator` 解析一行 CSV 数据 `"a,b,"c,d",e"`，打印每个字段。
4. 用 `boost::spirit::qi` 解析形如 `"3.14,2.71"` 的两个浮点数，存入两个 `double` 变量并打印。
