# 第 20 章 数值库

数值库是 C++ 标准库中与数学计算相关的设施集合，包括基础数学函数、特殊数学函数、数学常数、随机数生成、复数、数值数组，以及 C++26 前瞻的基础线性代数和 SIMD 数据并行类型。

本章覆盖：

- 20.1 常用数学函数、特殊数学函数与数学常数；
- 20.2 随机数生成与分布；
- 20.3 `complex`、`valarray` 与基础线性代数/SIMD（C++26 前瞻）。

核心原则依然是**选型**：需要高性能矩阵运算不要用 `valarray`，需要加密级随机数不要用 `mt19937`，需要复数运算用 `std::complex` 而不是自己写 struct。

> **工具约定**：示例以 C++20 为基线；`std::numbers` 数学常数是 C++20 特性，C++26 的 BLAS/SIMD 内容标注“前瞻”。代码片段可用 `cxxsh` 单文件验证，放入真实项目时请套用第 7.7 节的 CMake + vcpkg 工程模板。

## 20.1 常用数学函数、特殊数学函数与数学常数

### 20.1.1 常用数学函数（`<cmath>`）

`<cmath>` 提供了大量与 C 标准库兼容的数学函数，并为 `float`、`double`、`long double` 分别提供了重载，还增加了 `std::` 命名空间下的类型安全版本。

```cpp
// cmath_basic.cpp
#include <iostream>
#include <cmath>

int main() {
    double x = 2.0;

    std::cout << "std::sqrt(2) = " << std::sqrt(x) << '\n';
    std::cout << "std::pow(2, 3) = " << std::pow(x, 3.0) << '\n';
    std::cout << "std::exp(1) = " << std::exp(1.0) << '\n';
    std::cout << "std::log(2.71828) = " << std::log(2.71828) << '\n';
    std::cout << "std::sin(3.14159/2) = " << std::sin(3.14159 / 2) << '\n';
    std::cout << "std::fabs(-3.5) = " << std::fabs(-3.5) << '\n';
    std::cout << "std::floor(3.7) = " << std::floor(3.7) << '\n';
    std::cout << "std::ceil(3.2) = " << std::ceil(3.2) << '\n';
    std::cout << "std::round(3.5) = " << std::round(3.5) << '\n';
    std::cout << "std::hypot(3, 4) = " << std::hypot(3.0, 4.0) << '\n';  // sqrt(3^2+4^2)=5
}
```

输出：

```
std::sqrt(2) = 1.41421
std::pow(2, 3) = 8
std::exp(1) = 2.71828
std::log(2.71828) = 1
std::sin(3.14159/2) = 1
std::fabs(-3.5) = 3.5
std::floor(3.7) = 3
std::ceil(3.2) = 4
std::round(3.5) = 4
std::hypot(3, 4) = 5
```

常用函数速查：

| 函数 | 含义 |
|---|---|
| `std::sqrt(x)` | 平方根 |
| `std::pow(x, y)` | x 的 y 次幂 |
| `std::exp(x)` | e^x |
| `std::log(x)` | 自然对数 ln(x) |
| `std::log10(x)` | 常用对数 log10(x) |
| `std::sin/cos/tan(x)` | 三角函数（弧度） |
| `std::asin/acos/atan(x)` | 反三角函数 |
| `std::fabs(x)` | 绝对值（浮点） |
| `std::floor(x)` / `std::ceil(x)` | 向下/向上取整 |
| `std::round(x)` | 四舍五入 |
| `std::hypot(x, y)` | 平方和开方，避免中间溢出 |
| `std::fmod(x, y)` | 浮点取模 |

**避坑**：`<cmath>` 函数作用于浮点类型。如果传入整数，会隐式转换为 `double`，返回 `double`；如果需要 `float` 版本，可以用 `std::sqrtf` 或 C++ 的重载 `std::sqrt(float)`。

### 20.1.2 特殊数学函数（C++17，`<cmath>`）

C++17 增加了一组**特殊数学函数**（special mathematical functions），用于科学和工程计算，如贝塞尔函数、椭圆积分、伽马函数等。它们都在 `std` 命名空间下，名字前缀通常对应数学符号。

```cpp
// special_functions_basic.cpp
// 需要 C++17 及以上
#include <iostream>
#include <cmath>

int main() {
    // 伽马函数：Γ(5) = 4! = 24
    std::cout << "std::tgamma(5) = " << std::tgamma(5.0) << '\n';

    // 贝塞尔函数第一种类第 0 阶：J0(1.0)
    std::cout << "std::cyl_bessel_j(0, 1.0) = " << std::cyl_bessel_j(0, 1.0) << '\n';

    // 完整椭圆积分第二种类：E(k)
    std::cout << "std::comp_ellint_2(0.5) = " << std::comp_ellint_2(0.5) << '\n';
}
```

常用特殊函数：
- `std::tgamma(x)`：伽马函数 Γ(x)，对正整数 n，Γ(n) = (n-1)!；
- `std::cyl_bessel_j(n, x)`：第一类贝塞尔函数 J_n(x)；
- `std::cyl_neumann(n, x)`：第二类贝塞尔函数 Y_n(x)；
- `std::comp_ellint_1(k)` / `std::comp_ellint_2(k)`：完整椭圆积分；
- `std::hermite(n, x)`、`std::laguerre(n, x)`、`std::legendre(n, x)`：正交多项式。

这些函数在日常业务开发中很少用到，主要面向科学计算、信号处理、物理仿真等领域。如果你需要它们，通常已经知道具体要哪个函数。

### 20.1.3 数学常数（C++20，`<numbers>`）

C++20 在 `<numbers>` 头文件中提供了一组编译期数学常数，避免手写 `3.14159265358979323846` 这类魔法数字。

```cpp
// math_constants_basic.cpp
// 需要 C++20
#include <iostream>
#include <numbers>
#include <cmath>

int main() {
    std::cout << "π = " << std::numbers::pi << '\n';
    std::cout << "e = " << std::numbers::e << '\n';
    std::cout << "ln(2) = " << std::numbers::ln2 << '\n';
    std::cout << "sqrt(2) = " << std::numbers::sqrt2 << '\n';
    std::cout << "黄金分割比 = " << std::numbers::phi << '\n';

    // 计算圆面积：π * r^2
    double r = 5.0;
    double area = std::numbers::pi * r * r;
    std::cout << "半径 5 的圆面积：" << area << '\n';
}
```

可能的输出：

```
π = 3.14159
e = 2.71828
ln(2) = 0.693147
sqrt(2) = 1.41421
黄金分割比 = 1.61803
半径 5 的圆面积：78.5398
```

`std::numbers` 常量都是 `constexpr`，可以在编译期使用，例如定义数组大小：

```cpp
constexpr double PI = std::numbers::pi;
double sin_table[static_cast<int>(PI * 100)];  // 编译期常量
```

### 20.1.4 选型建议

| 需求 | 推荐 | 原因 |
|---|---|---|
| 基础三角、对数、指数、幂 | `std::sqrt`、`std::sin`、`std::exp` 等（`<cmath>`） | 标准库直接提供，类型安全 |
| 科学计算中的特殊函数 | C++17 特殊数学函数（`<cmath>`） | 避免自己实现易出错的数值算法 |
| 需要 π、e 等常数 | `std::numbers::pi` 等（C++20） | 精度高、可编译期使用、无魔法数字 |
| 高性能向量数学（大量向量乘法） | 第三方库（Eigen、GLM、DirectXMath） | 标准库不提供向量/矩阵运算 |

> **反例**：不要在性能敏感的循环里反复手写 `3.1415926`，应该用 `std::numbers::pi`；不要为了求圆周率自己写莱布尼茨级数，标准库常量已经够精确。

## 20.2 随机数生成与分布

### 20.2.1 随机数设计：引擎 + 分布

C++ 随机数库（`<random>`）把“随机数生成”拆成两个部分：

1. **随机数引擎（engine）**：产生均匀分布的原始随机整数，如 `std::mt19937`（梅森旋转算法）；
2. **分布（distribution）**：把引擎产生的原始数转换成特定概率分布，如 `std::uniform_int_distribution`（均匀整数分布）、`std::normal_distribution`（正态分布）。

```cpp
// random_basic.cpp
#include <iostream>
#include <random>

int main() {
    // 1. 创建随机数引擎，用 random_device 产生种子
    std::random_device rd;                      // 非确定性随机种子源
    std::mt19937 gen(rd());                     // 梅森旋转引擎，以 rd() 结果种子

    // 2. 定义分布：[1, 6] 的均匀整数（模拟掷骰子）
    std::uniform_int_distribution<> dist(1, 6);

    // 3. 生成 10 次
    for (int i = 0; i < 10; ++i) {
        std::cout << dist(gen) << ' ';          // dist 使用 gen 产生随机数
    }
    std::cout << '\n';
}
```

可能的输出：

```
4 2 6 1 5 3 6 2 4 1 
```

关键点：
- `std::random_device` 是非确定性随机源（由操作系统提供，如 `/dev/urandom` 或 Windows 加密 API），用于产生种子，不宜直接用于大量生成（速度慢）；
- `std::mt19937` 是速度快、周期长的伪随机数引擎，适合大多数模拟和游戏场景；
- 分布对象可以重复使用，每次调用 `dist(gen)` 产生一个新随机数。

### 20.2.2 常见引擎与分布

| 引擎 | 特点 | 适用场景 |
|---|---|---|
| `std::mt19937` | 32 位梅森旋转，周期大、速度快 | 通用伪随机数 |
| `std::mt19937_64` | 64 位版本 | 需要 64 位随机数 |
| `std::random_device` | 非确定性随机源 | 产生种子，或少量真随机数 |
| `std::minstd_rand` | 简单线性同余，速度快但质量低 | 资源受限环境 |

| 分布 | 作用 | 示例参数 |
|---|---|---|
| `std::uniform_int_distribution` | 均匀整数分布 | `[a, b]` |
| `std::uniform_real_distribution` | 均匀实数分布 | `[a, b)` |
| `std::bernoulli_distribution` | 伯努利分布（0/1） | 概率 p |
| `std::normal_distribution` | 正态分布（高斯） | 均值 μ、标准差 σ |
| `std::poisson_distribution` | 泊松分布 | 平均发生率 λ |

```cpp
// random_distributions.cpp
#include <iostream>
#include <random>
#include <map>

int main() {
    std::random_device rd;
    std::mt19937 gen(rd());

    // 正态分布：均值 0，标准差 1
    std::normal_distribution<> normal(0.0, 1.0);
    std::cout << "正态分布样本：";
    for (int i = 0; i < 5; ++i) {
        std::cout << normal(gen) << ' ';
    }
    std::cout << '\n';

    // 伯努利分布：70% 概率得到 true
    std::bernoulli_distribution coin(0.7);
    int true_count = 0;
    for (int i = 0; i < 1000; ++i) {
        if (coin(gen)) ++true_count;
    }
    std::cout << "1000 次投掷中 true 出现 " << true_count << " 次（期望约 700）\n";
}
```

可能的输出：

```
正态分布样本：0.123 -0.456 1.234 ...
1000 次投掷中 true 出现 704 次（期望约 700）
```

### 20.2.3 选型与避坑

| 需求 | 推荐 | 原因 |
|---|---|---|
| 通用模拟、游戏随机数 | `std::mt19937` + 分布 | 质量好、速度快、可复现 |
| 需要确定可重现的序列（调试、测试） | 固定种子的 `std::mt19937(seed)` | 相同种子产生相同序列 |
| 安全敏感（密码、令牌、抽奖） | 不要用 `<random>`，用操作系统加密随机 API（如 Windows `BCryptGenRandom`、Linux `getrandom`） | `mt19937` 可预测，不适合安全场景 |
| 需要真随机种子 | `std::random_device` | 非确定性种子源 |

**反例**：不要用 `std::rand()`（`<cstdlib>`）。`rand()` 是全局状态、线程不安全、质量差、范围小（通常只有 15 位），现代 C++ 代码中应完全避免。

## 20.3 `complex`、`valarray` 与基础线性代数/SIMD（C++26 前瞻）

### 20.3.1 `std::complex<T>`：复数

`std::complex<T>`（`<complex>`）表示复数，`T` 可以是 `float`、`double`、`long double`。它重载了四则运算、比较、流输入输出等运算符。

```cpp
// complex_basic.cpp
#include <iostream>
#include <complex>

int main() {
    std::complex<double> z1(3.0, 4.0);   // 3 + 4i
    std::complex<double> z2(1.0, -1.0);  // 1 - 1i

    std::cout << "z1 = " << z1 << '\n';
    std::cout << "z2 = " << z2 << '\n';
    std::cout << "z1 + z2 = " << (z1 + z2) << '\n';
    std::cout << "z1 * z2 = " << (z1 * z2) << '\n';
    std::cout << "|z1| = " << std::abs(z1) << '\n';   // 模长 5
}
```

输出：

```
z1 = (3,4)
z2 = (1,-1)
z1 + z2 = (4,3)
z1 * z2 = (7,1)
|z1| = 5
```

`std::complex` 适合信号处理、电路分析、量子力学等涉及复数运算的场景。日常业务开发中很少用到。

### 20.3.2 `std::valarray<T>`：数值数组

`std::valarray<T>`（`<valarray>`）是专为数值计算设计的数组类，支持元素级的向量化运算（如 `a = b * c + d` 会对每个元素分别计算）。

```cpp
// valarray_basic.cpp
#include <iostream>
#include <valarray>

int main() {
    std::valarray<double> a = {1.0, 2.0, 3.0, 4.0};
    std::valarray<double> b = {10.0, 20.0, 30.0, 40.0};

    auto c = a * b + 1.0;   // 元素级运算：{11, 41, 91, 161}
    double sum = c.sum();   // 304

    std::cout << "sum = " << sum << '\n';
}
```

输出：

```
sum = 304
```

然而，`std::valarray` 的API 设计古老、不够直观，且编译器优化支持不一，现代 C++ 中**很少直接使用**。如果你需要高性能矩阵/向量运算，应该用第三方数学库，如 **Eigen**、**GLM**、**Armadillo** 或 **BLAS/LAPACK** 绑定。

### 20.3.3 C++26 基础线性代数与 SIMD（前瞻）

C++26 正在标准化两项与数值计算相关的前瞻特性：

1. **基础线性代数算法（BLAS 风格）**：标准库将提供矩阵向量乘法、点积、范数等基础线性代数操作，基于 `std::mdspan`（见第 9 章）表示多维数组视图。这属于**C++26 前瞻**，编译器支持有限，生产环境请谨慎。
2. **SIMD 数据并行类型**：标准库将提供与硬件指令集（SSE、AVX、NEON 等）对应的数据并行类型，允许对一组数据执行同一指令。这也属于**C++26 前瞻**。

这两项内容目前主要面向高性能计算、游戏引擎、科学仿真等领域，初学者只需要知道“C++26 会有标准化的线性代数和 SIMD 支持”即可，不需要深入。

> **小结**：`std::complex` 处理复数；`std::valarray` 是老式数值数组，现代项目推荐第三方数学库（Eigen 等）；C++26 的基础线性代数和 SIMD 属前瞻特性，暂不宜在生产核心代码依赖。

## 本章小结

本章我们学习了标准库数值设施的核心内容：

1. **常用数学函数**：`<cmath>` 提供 `sqrt`、`sin`、`exp`、`pow` 等，重载支持 `float`/`double`/`long double`；
2. **特殊数学函数（C++17）**：`tgamma`、`cyl_bessel_j`、`comp_ellint_2` 等，面向科学计算；
3. **数学常数（C++20）**：`<numbers>` 提供 `std::numbers::pi`、`e`、`ln2` 等，是 `constexpr` 编译期常量；
4. **随机数生成**：引擎（`mt19937`）+ 分布（`uniform_int_distribution`、`normal_distribution` 等）的分离设计，`random_device` 产生种子；
5. **随机数选型**：通用用 `mt19937`，安全场景不要用标准库随机数，不要用 `rand()`；
6. **`std::complex`**：复数运算，适合信号处理等领域；
7. **`std::valarray`**：老式数值数组，现代项目推荐 Eigen 等第三方库；
8. **C++26 前瞻**：基础线性代数（BLAS 风格）和 SIMD 数据并行类型，生产环境谨慎使用。

选型口诀：**数学函数用 `<cmath>`，常数用 `std::numbers`，随机数用 `mt19937`+分布，安全随机用系统加密 API，矩阵运算用 Eigen，复数用 `std::complex`。**

## 练习

1. 写一个程序，计算半径为 5 的圆的面积和周长，使用 `std::numbers::pi`。
2. 用 `std::mt19937` 和 `std::uniform_int_distribution<>` 模拟掷 6 面骰子 100 次，统计每个点数出现的次数。
3. 用 `std::normal_distribution<>` 生成 1000 个正态分布随机数（均值 0，标准差 1），计算样本均值，观察是否接近 0。
4. 用 `std::complex<double>` 做复数加法、乘法，并计算模长，打印结果。
5. 用 `std::accumulate` 配合 `std::sqrt` 计算一个向量里所有元素平方和的平方根（即欧几里得范数）。
