# 第 26 章 Boost 通用工具与函数式设施

Boost 提供了一组通用工具和函数式设施，其中一些已经被标准库吸收（如 `boost::function` → `std::function`、`boost::bind` → `std::bind`、`boost::signals2` 仍有独特价值），一些在标准库里有对应但 Boost 版本有不同侧重（如 `boost::lexical_cast` vs `std::to_chars`/`std::format`），一些则是纯 Boost 独有（如 `boost::signals2` 的线程安全信号槽、`boost::property_map` 的图属性映射、`boost::dynamic_bitset` 的动态位集）。

本章覆盖：

- 26.1 `boost::function`、`boost::bind` 与 `boost::signals2`；
- 26.2 `boost::lexical_cast` 与类型转换；
- 26.3 `boost::property_map` 与 `boost::dynamic_bitset`。

每一节都会标注该设施的定位：**已被标准化 / 部分标准化 / 纯 Boost 独有**。

> **工具约定**：示例默认采用 CMake + vcpkg 工程模板，Boost 依赖通过 vcpkg 清单引入。Boost.Function、Boost.Bind、Boost.LexicalCast、Boost.PropertyMap、Boost.DynamicBitset 大多是 header-only，Boost.Signals2 也是 header-only。代码片段可用 `cxxsh` 单文件验证，放入真实项目时请套用第 7.7 节的工程模板。

## 26.1 `boost::function`、`boost::bind` 与 `boost::signals2`

### 26.1.1 `boost::function`：标准库 `std::function` 的前身

`boost::function`（`<boost/function.hpp>`）是 C++11 `std::function` 的前身，提供类型擦除的可调用对象包装器，可以存储普通函数、函数指针、Lambda、仿函数等。

定位：**已被标准化**（C++11 `std::function`）。新代码优先用 `std::function`（或 C++23 的 `std::move_only_function`），`boost::function` 仅用于旧项目兼容或需要 Boost.Function 特有扩展的场景。

```cpp
// boost_function_basic.cpp
// Boost.Function 是 header-only，无需链接库文件
#include <iostream>
#include <boost/function.hpp>
#include <string>

void hello() {
    std::cout << "Hello from function\n";
}

int main() {
    boost::function<void()> f = hello;
    f();

    f = [] { std::cout << "Hello from lambda\n"; };
    f();
}
```

输出：

```
Hello from function
Hello from lambda
```

### 26.1.2 `boost::bind`：参数绑定的前标准方案

`boost::bind`（`<boost/bind.hpp>`）是 C++11 `std::bind` 的前身，用于把可调用对象的部分参数绑定，产生一个新的可调用对象。

定位：**已被标准化**（C++11 `std::bind`、C++20 `std::bind_front`、`std::bind_back`）。新代码优先用标准库，`boost::bind` 仅用于旧项目。

```cpp
// boost_bind_basic.cpp
// Boost.Bind 是 header-only，无需链接库文件
#include <iostream>
#include <boost/bind.hpp>

void print_prefix(int level, const std::string& msg) {
    std::cout << "[" << level << "] " << msg << "\n";
}

int main() {
    // 绑定第一个参数为 1，得到一个只需要 msg 的可调用对象
    auto log_info = boost::bind(print_prefix, 1, _1);
    log_info("系统启动");
}
```

输出：

```
[1] 系统启动
```

这里 `_1` 是 Boost.Bind 的占位符，表示第一个未绑定参数。

### 26.1.3 `boost::signals2`：线程安全的信号/槽（纯 Boost 独有）

`boost::signals2`（`<boost/signals2.hpp>`）是 Boost 信号槽库，实现了发布/订阅模式：一个“信号”可以连接多个“槽”（回调函数），信号触发时所有槽都会被调用。与普通函数指针或 `std::function` 不同，`signals2` 支持**多对多**连接、自动生命周期管理（槽对象销毁时自动断开连接）和**线程安全**。

定位：**纯 Boost 独有**（标准库没有信号槽机制，C++23 也没有标准化计划）。

```cpp
// boost_signals2_basic.cpp
// Boost.Signals2 是 header-only，无需链接库文件
#include <iostream>
#include <boost/signals2.hpp>

int main() {
    boost::signals2::signal<void(int)> sig;

    // 连接两个槽
    sig.connect([](int x) { std::cout << "槽 A 收到：" << x << "\n"; });
    sig.connect([](int x) { std::cout << "槽 B 收到：" << x * 2 << "\n"; });

    // 触发信号，所有槽都被调用
    sig(21);

    // 断开一个槽后再触发
    sig.disconnect_all_slots();
    sig(5);  // 无输出
}
```

输出：

```
槽 A 收到：21
槽 B 收到：42
```

`signals2` 的典型应用场景是 GUI 事件处理、游戏引擎的事件总线、插件系统的回调等：发送方不需要知道接收方是谁，只需要“发出一个信号”，感兴趣的接收方自己订阅。

`signals2` 还支持连接返回值的聚合（如多个槽都返回 bool，信号可以返回“任何一个为 true 就算 true”`), 以及在信号发射期间安全地连接/断开槽。

### 26.1.4 选型建议

| 需求 | 推荐 | 原因 |
|---|---|---|
| 类型擦除的可调用包装器 | `std::function` / `std::move_only_function` | 标准库，新代码优先 |
| 参数绑定 | `std::bind` / `std::bind_front` / `std::bind_back` 或 Lambda | 标准库，更简洁 |
| 多对多发布/订阅、线程安全信号槽 | `boost::signals2` | 标准库无对应，Boost 独有 |

## 26.2 `boost::lexical_cast` 与类型转换

### 26.2.1 字符串与数值之间的简单转换

`boost::lexical_cast<T>(source)`（`<boost/lexical_cast.hpp>`）在字符串和数值/其他类型之间做双向转换，底层基于流（`std::stringstream`），语法比 `std::stoi`/`std::to_string` 更统一，出错时抛出 `boost::bad_lexical_cast`。

定位：**部分标准化**（C++17 `std::to_chars`/`std::from_chars`（`<charconv>`）和 C++20 `std::format` 提供了更高性能的替代，但 `boost::lexical_cast` 的接口更统一、支持更多类型）。

```cpp
// boost_lexical_cast_basic.cpp
// Boost.LexicalCast 是 header-only，无需链接库文件
#include <iostream>
#include <string>
#include <boost/lexical_cast.hpp>

int main() {
    using namespace boost;

    int i = lexical_cast<int>("42");
    double d = lexical_cast<double>("3.14");
    std::string s = lexical_cast<std::string>(100);

    std::cout << i << ", " << d << ", " << s << "\n";

    // 转换失败会抛出 boost::bad_lexical_cast
    try {
        lexical_cast<int>("不是数字");
    } catch (const bad_lexical_cast& e) {
        std::cout << "转换失败：" << e.what() << "\n";
    }
}
```

输出：

```
42, 3.14, 100
转换失败：bad lexical cast: source type value could not be interpreted as target
```

### 26.2.2 三种类型转换设施的对比

| 设施 | 方向 | 性能 | 类型范围 | 标准化 |
|---|---|---|---|---|
| `boost::lexical_cast<T>` | 字符串 ↔ 各类型 | 中（基于流） | 很广 | 部分标准化（`std::format` 替代部分场景） |
| `std::stoi`/`std::to_string` 等 | 字符串 ↔ 数值 | 中 | 仅数值 | 标准库（C++11） |
| `std::to_chars`/`std::from_chars` | 数值 ↔ 字符缓冲区 | 极高（无分配、无异常） | 仅数值 | 标准库（C++17） |
| `std::format` | 各类型 → 字符串 | 高 | 很广 | 标准库（C++20） |

选型建议：
- 日常字符串与数值转换，且不追求极致性能：`boost::lexical_cast` 接口统一，代码简洁；
- 性能敏感、不分配内存、不抛异常：`std::to_chars`/`std::from_chars`；
- 构造格式化字符串：C++20 用 `std::format`，旧项目用 `boost::format`；
- 新代码中若已用 C++17/20，优先标准设施，减少对 Boost 的依赖。

## 26.3 `boost::property_map` 与 `boost::dynamic_bitset`

### 26.3.1 `boost::property_map`：图/容器属性映射

`boost::property_map`（`<boost/property_map/property_map.hpp>`）是 Boost 图库（BGL）等库使用的属性映射抽象：它把“键 → 属性值”的映射抽象成一个统一接口，不管底层是 `std::map`、数组、还是用户自定义的存储。

定位：**纯 Boost 独有**（标准库没有属性映射抽象，主要用于 Boost.Graph 等图算法库）。

简单示例：

```cpp
// boost_property_map_basic.cpp
// Boost.PropertyMap 是 header-only，无需链接库文件
#include <iostream>
#include <vector>
#include <boost/property_map/property_map.hpp>

int main() {
    using namespace boost;

    std::vector<int> values = {10, 20, 30, 40};

    // 把 vector 把成 property_map：索引作为键，值作为属性
    auto pm = make_iterator_property_map(values.begin(), identity_property_map());

    // 读写属性
    std::cout << "values[2] = " << get(pm, 2) << "\n";
    put(pm, 2, 99);
    std::cout << "values[2] = " << get(pm, 2) << "\n";
}
```

输出：

```
values[2] = 30
values[2] = 99
```

`property_map` 的核心抽象是 `get(pm, key)` 和 `put(pm, key, value)`，配合 `iterator_property_map` 可以把任意随机访问容器当作属性图使用。它主要服务于 Boost.Graph（BGL）等图算法，日常业务代码中很少直接用到。

### 26.3.2 `boost::dynamic_bitset`：动态大小位集

`std::bitset<N>`（第 8 章讲过）的大小 `N` 必须是编译期常量。如果位数在运行期才确定，或者需要动态增减位数，可以用 `boost::dynamic_bitset`（`<boost/dynamic_bitset.hpp>`）。

定位：**纯 Boost 独有**（标准库没有动态大小位集；`std::vector<bool>` 可以部分替代但 API 不同且有已知陷阱）。

```cpp
// boost_dynamic_bitset_basic.cpp
// Boost.DynamicBitset 是 header-only，无需链接库文件
#include <iostream>
#include <boost/dynamic_bitset.hpp>

int main() {
    using namespace boost;

    // 运行期指定大小
    std::size_t n = 10;
    dynamic_bitset<> bits(n);

    bits.set(0);
    bits.set(3);
    bits.set(9);

    std::cout << "位数：" << bits.size() << "\n";
    std::cout << "置 1 的个数：" << bits.count() << "\n";
    std::cout << "位串：";
    for (std::size_t i = 0; i < bits.size(); ++i) {
        std::cout << bits[i];
    }
    std::cout << "\n";

    // 动态扩容
    bits.resize(20);
    bits.set(15);
    std::cout << "扩容后位数：" << bits.size() << ", 第 15 位：" << bits[15] << "\n";
}
```

输出：

```
位数：10
置 1 的个数：3
位串：1001000000
扩容后位数：20, 第 15 位：1
```

`dynamic_bitset` 支持 `set`、`reset`、`flip`、`test`、`count`、`any`/`none`/`all`、`operator[]` 等操作，底层按字存储，位运算高效。

### 26.3.3 选型建议

| 需求 | 推荐 | 原因 |
|---|---|---|
| 字符串与各类型互转，接口统一 | `boost::lexical_cast` | 旧项目或需要统一接口 |
| 高性能数值↔字符串转换 | `std::to_chars`/`std::from_chars`（C++17）| 无分配、无异常 |
| 格式化字符串 | `std::format`（C++20）或 `boost::format` | 标准库优先 |
| 图/容器属性映射（主要用于 BGL）| `boost::property_map` | Boost 独有，服务于图算法 |
| 运行期位数可变的位集 | `boost::dynamic_bitset` | `std::bitset` 大小必须是编译期常量 |

## 本章小结

本章我们学习了 Boost 通用工具与函数式设施：

1. **`boost::function`**：已被标准化，新代码优先 `std::function` / `std::move_only_function`；
2. **`boost::bind`**：已被标准化，新代码优先 `std::bind` / `std::bind_front/back` 或 Lambda；
3. **`boost::signals2`**：纯 Boost 独有，线程安全的信号/槽发布订阅，适合 GUI 事件总线、插件回调；
4. **`boost::lexical_cast`**：部分标准化，字符串与各类型的统一转换，新代码优先 `std::to_chars`/`std::format`；
5. **`boost::property_map`**：纯 Boost 独有，属性映射抽象，主要用于 Boost.Graph 等图算法库；
6. **`boost::dynamic_bitset`**：纯 Boost 独有，运行期大小可变的位集，`std::bitset` 无法满足时使用。

选型口诀：**可调用包装用 `std::function`；参数绑定用 Lambda 或 `std::bind`；多对多回调用 `signals2`；字符串转换旧代码用 `lexical_cast`，新代码用 `to_chars`/`format`；动态位集用 `dynamic_bitset`。**

下一章（第 27 章）我们进入 Boost 数值、日期时间与文件系统，学习 `boost::multiprecision`、`boost::date_time`、`boost::chrono`、`boost::filesystem`。
