# 第 16 章 概念库与元编程库

第 5 章我们学习了模板和概念（concepts）的基础。本章继续深入标准库提供的**概念库**（`<concepts>`）和**元编程基础设施**（`<type_traits>`、`<ratio>` 等）。这些设施大多在编译期工作，不产生运行期开销，但能让你的泛型代码更安全、更易读、更易维护。

本章覆盖：

- 16.1 基本库概念：`std::same_as`、`std::convertible_to`、`std::integral`、`std::invocable` 等；
- 16.2 编译期类型信息与 `std::integral_constant`；
- 16.3 编译时有理数运算与 `std::ratio`。

> **工具约定**：示例以 C++20 为基线；概念和 `std::integral_constant` 都是 C++20/C++11 起可用，`std::ratio` 是 C++11 起可用。代码片段可用 `cxxsh` 单文件验证，放入真实项目时请套用第 7.7 节的 CMake + vcpkg 工程模板。

## 16.1 基本库概念：`same_as`、`convertible_to`、`integral`、`invocable` 等

### 16.1.1 什么是“概念”

概念（concept）是 C++20 引入的编译期谓词，用来对模板参数提出明确要求。标准库的 `<concepts>` 头文件提供了一大批开箱即用的概念，覆盖了类型关系、函数可调用性、整数、浮点数等常见场景。

使用概念有两种常见写法：

1. **简写模板**：`template <std::integral T>`，等价于 `template <typename T> requires std::integral<T>`；
2. **`requires` 子句**：`template <typename T> requires std::integral<T>`，更显式，适合复杂约束。

下面是一个最简单的例子，只允许整数类型调用：

```cpp
// concepts_basic.cpp
#include <iostream>
#include <concepts>

template <std::integral T>
T gcd(T a, T b) {
    while (b != 0) {
        T temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

int main() {
    std::cout << gcd(48, 18) << '\n';   // 6，T = int，满足 integral
    // std::cout << gcd(3.14, 2.5) << '\n';  // 编译错误：double 不满足 integral
}
```

如果传入不满足概念的类型，编译器会直接报错，并且错误信息会清楚地指出“类型不满足 integral 概念”，而不是抛出几十行模板实例化的堆栈。

### 16.1.2 常用概念速查表

标准库提供的常用概念（全部在 `<concepts>` 头文件）：

| 概念 | 含义 | 典型用途 |
|---|---|---|
| `std::same_as<T, U>` | `T` 和 `U` 是同一类型 | 约束两个模板参数必须相同 |
| `std::convertible_to<T, U>` | `T` 能隐式转换为 `U` | 约束返回值能转成目标类型 |
| `std::integral<T>` | `T` 是整数类型（bool、char、int 等） | 只接受整数的算法 |
| `std::floating_point<T>` | `T` 是浮点类型 | 只接受浮点数的算法 |
| `std::invocable<F, Args...>` | `F` 可以用 `Args...` 实参调用 | 约束可调用对象 |
| `std::regular<T>` | `T` 是常规类型（可复制、可比较、可析构等） | 约束值类型 |
| `std::totally_ordered<T>` | `T` 支持全序比较（`<`、`<=`、`>`、`>=`） | 排序算法的键类型 |
| `std::equality_comparable<T>` | `T` 支持 `==` 和 `!=` | 容器查找的键类型 |

示例：`std::convertible_to` 确保一个值能安全地转换为另一种类型：

```cpp
// convertible_to_basic.cpp
#include <iostream>
#include <concepts>

template <std::convertible_to<double> T>
double to_double(T value) {
    return static_cast<double>(value);
}

int main() {
    std::cout << to_double(42) << '\n';        // int 可转 double
    std::cout << to_double(3.14f) << '\n';     // float 可转 double
    // std::cout << to_double(std::string("abc")) << '\n';  // 编译错误
}
```

### 16.1.3 自定义概念

标准库的概念不够用时，可以自己定义。定义概念的语法是 `concept 名称 = 约束表达式;`，通常配合 `requires` 表达式：

```cpp
// custom_concept.cpp
#include <iostream>
#include <concepts>
#include <string>

// 自定义概念：要求类型支持 == 比较，且返回结果可转换为 bool
template <typename T>
concept EqualityComparable = requires(T a, T b) {
    { a == b } -> std::convertible_to<bool>;
};

template <EqualityComparable T>
bool are_equal(T a, T b) {
    return a == b;
}

struct Point {
    int x, y;
    bool operator==(const Point&) const = default;
};

int main() {
    std::cout << are_equal(3, 4) << '\n';       // int 支持 ==
    Point p1{1, 2}, p2{1, 2};
    std::cout << are_equal(p1, p2) << '\n';     # Point 支持 ==
}
```

`requires` 表达式里的 `{ a == b } -> std::convertible_to<bool>;` 表示：表达式 `a == b` 是合法的，且结果能隐式转换为 `bool`。

### 16.1.4 概念组合与简写

概念可以用 `&&`、`||`、`!` 组合：

```cpp
template <typename T>
concept Numeric = std::integral<T> || std::floating_point<T>;

template <Numeric T>
T square(T x) {
    return x * x;
}
```

`Numeric` 表示“整数或浮点数”，`square` 只接受数字类型。

简写模板 `template <Numeric T>` 只是 `template <typename T> requires Numeric<T>` 的语法糖，两者完全等价。

> **小结**：`<concepts>` 提供了 `same_as`、`convertible_to`、`integral`、`invocable` 等开箱即用的概念；用概念约束模板参数，错误信息清晰，意图明确；不够用时可用 `requires` 表达式自定义概念，并用 `&&`/`||`/`!` 组合。

## 16.2 编译期类型信息与 `std::integral_constant`

### 16.2.1 `std::integral_constant`：编译期值的载体

`std::integral_constant<T, v>`（`<type_traits>`）是一个极简的模板结构体，它只做一件事：把一个编译期常量值 `v` 包装成一个类型。它是 C++ 编译期元编程的“Hello World”级基础设施，也是 `std::true_type` / `std::false_type` 的基础。

```cpp
// integral_constant_basic.cpp
#include <iostream>
#include <type_traits>

int main() {
    using true_type = std::integral_constant<bool, true>;
    using false_type = std::integral_constant<bool, false>;

    std::cout << "true_type::value = " << true_type::value << '\n';     // 1
    std::cout << "false_type::value = " << false_type::value << '\n';   // 0
    std::cout << "true_type() = " << true_type() << '\n';               // 1（可转 bool）
}
```

`std::integral_constant` 有两个关键成员：
- `value`：`static constexpr T value = v;`，编译期常量；
- `operator T()`：可以隐式转换为 `T`，方便在表达式中直接用。

标准库基于它定义了两个别名：

```cpp
using std::true_type  = std::integral_constant<bool, true>;
using std::false_type = std::integral_constant<bool, false>;
```

### 16.2.2 `bool_constant`：更便捷的布尔常量

C++17 还提供了 `std::bool_constant<B>`，它是 `std::integral_constant<bool, B>` 的别名，更简洁：

```cpp
#include <type_traits>

std::bool_constant<true>  b1;   // 等价于 std::true_type
std::bool_constant<false> b2;   // 等价于 std::false_type
```

### 16.2.3 实际用途：编译期条件分发

`integral_constant` 最常见的用途是配合重载或 `if constexpr` 做编译期条件分发。比如写一个模板函数，根据 `T` 是否是整数类型，走不同的代码路径：

```cpp
// integral_constant_dispatch.cpp
#include <iostream>
#include <type_traits>
#include <string>

template <typename T>
void process(T value, std::true_type) {   // 是整数类型
    std::cout << "整数路径，值为：" << value << '\n';
}

template <typename T>
void process(T value, std::false_type) {  // 不是整数类型
    std::cout << "非整数路径，值为：" << value << '\n';
}

template <typename T>
void dispatch(T value) {
    // 根据 std::is_integral_v<T> 是 true 还是 false，选不同的重载
    process(value, std::integral_constant<bool, std::is_integral_v<T>>{});
}

int main() {
    dispatch(42);            // 整数路径
    dispatch(3.14);          // 非整数路径
    dispatch(std::string("hi"));  // 非整数路径
}
```

输出：

```
整数路径，值为：42
非整数路径，值为：3.14
非整数路径，值为：hi
```

不过，现代 C++ 中这种模式通常直接用 `if constexpr (std::is_integral_v<T>)` 就能完成，更简洁。`integral_constant` 的主要价值在于：它是很多标准类型特征（`std::is_integral`、`std::is_same` 等）的返回类型，也是理解“编译期常量如何以类型形式存在”的基础。

> **小结**：`std::integral_constant<T, v>` 把编译期常量包装成类型，提供 `value` 成员和向 `T` 的转换；`std::true_type`/`std::false_type` 是它的布尔特化；`std::bool_constant<B>` 是 C++17 的简洁别名。它是编译期元编程的基础构件，日常代码中更常直接用 `std::is_*_v` 变量模板和 `if constexpr`。

## 16.3 编译时有理数运算与 `std::ratio`

### 16.3.1 什么是 `std::ratio`

`std::ratio<N, D>`（`<ratio>`）表示一个编译期的有理数 `N / D`，分子 `N` 和分母 `D` 都是编译期整数，标准库会自动将其约分为最简形式。它最典型的应用场景是 `std::chrono` 的时间单位（`std::chrono::seconds`、`std::chrono::milliseconds` 等底层都用 `std::ratio` 表示比例关系）。

```cpp
// ratio_basic.cpp
#include <iostream>
#include <ratio>

int main() {
    using one_half = std::ratio<1, 2>;        // 1/2
    using one_third = std::ratio<1, 3>;       // 1/3
    using two_fourths = std::ratio<2, 4>;     // 会被自动约分为 1/2

    std::cout << "one_half: " << one_half::num << '/' << one_half::den << '\n';   // 1/2
    std::cout << "one_third: " << one_third::num << '/' << one_third::den << '\n'; // 1/3
    std::cout << "two_fourths: " << two_fourths::num << '/' << two_fourths::den << '\n'; // 1/2（自动约分）
}
```

输出：

```
one_half: 1/2
one_third: 1/3
two_fourths: 1/2
```

`std::ratio` 提供两个 `static constexpr` 成员：
- `num`：分子（约分后）；
- `den`：分母（约分后，且为正）。

### 16.3.2 有理数元函数：加减乘除与比较

`<ratio>` 提供了一组元函数，对两个 `std::ratio` 做编译期运算，结果也是一个 `std::ratio`，且自动约分：

| 元函数 | 含义 |
|---|---|
| `std::ratio_add<R1, R2>` | 相加 |
| `std::ratio_subtract<R1, R2>` | 相减 |
| `std::ratio_multiply<R1, R2>` | 相乘 |
| `std::ratio_divide<R1, R2>` | 相除 |
| `std::ratio_equal<R1, R2>` | 判断相等（`std::true_type` / `std::false_type`） |
| `std::ratio_less<R1, R2>` | 判断小于 |
| `std::ratio_less_equal<R1, R2>` | 判断小于等于 |
| `std::ratio_greater<R1, R2>` | 判断大于 |
| `std::ratio_greater_equal<R1, R2>` | 判断大于等于 |

```cpp
// ratio_ops.cpp
#include <iostream>
#include <ratio>

int main() {
    using half = std::ratio<1, 2>;
    using third = std::ratio<1, 3>;

    using sum = std::ratio_add<half, third>::type;       // 1/2 + 1/3 = 5/6
    using product = std::ratio_multiply<half, third>::type; // 1/2 * 1/3 = 1/6

    std::cout << "1/2 + 1/3 = " << sum::num << '/' << sum::den << '\n';       // 5/6
    std::cout << "1/2 * 1/3 = " << product::num << '/' << product::den << '\n'; // 1/6

    using is_equal = std::ratio_equal<half, std::ratio<2, 4>>;  // 1/2 == 2/4（约分后相等）
    std::cout << "1/2 == 2/4? " << is_equal::value << '\n';      // 1（true）
}
```

输出：

```
1/2 + 1/3 = 5/6
1/2 * 1/3 = 1/6
1/2 == 2/4? 1
```

所有运算都在**编译期**完成，结果类型直接编译进二进制，没有任何运行期开销。

### 16.3.3 `std::ratio` 的典型应用：时间单位

`std::chrono` 的时间单位就是基于 `std::ratio` 构建的。例如：

- `std::chrono::seconds` 对应 `std::ratio<1>`（1 秒 = 1/1 秒）；
- `std::chrono::milliseconds` 对应 `std::ratio<1, 1000>`（1 毫秒 = 1/1000 秒）；
- `std::chrono::microseconds` 对应 `std::ratio<1, 1000000>`。

不同单位的时间点和时长可以相互转换，编译器会根据 `std::ratio` 的比例自动生成转换代码，且转换是类型安全的。

```cpp
// ratio_in_chrono.cpp
#include <iostream>
#include <chrono>

int main() {
    std::chrono::milliseconds ms(1500);
    std::chrono::seconds s = std::chrono::duration_cast<std::chrono::seconds>(ms);
    std::cout << "1500 毫秒 = " << s.count() << " 秒\n";   // 1 秒（截断）
}
```

### 16.3.3 选型建议

| 需求 | 推荐设施 | 备注 |
|---|---|---|
| 编译期表示固定比例（如时间单位、物理单位） | `std::ratio<N, D>` | 编译期运算，零运行期开销 |
| 编译期比较两个有理数 | `std::ratio_equal` / `ratio_less` 等 | 返回 `true_type` / `false_type` |
| 日常编程中表示分数 | 直接用 `double` 或自定义有理数类 | `std::ratio` 主要服务于编译期元编程和 `chrono` |

> **小结**：`std::ratio` 表示编译期有理数，自动约分；`ratio_add`/`ratio_multiply` 等元函数在编译期做运算；`std::chrono` 的时间单位底层基于 `std::ratio`。它适合“编译期就确定比例关系”的场景，不适合运行期动态计算分数。

## 本章小结

本章我们学习了概念库与元编程基础设施：

1. **概念库（`<concepts>`）**：`std::same_as`、`std::convertible_to`、`std::integral`、`std::floating_point`、`std::invocable` 等，用于对模板参数提出明确要求；不够用时可用 `requires` 表达式自定义概念，并用 `&&`/`||`/`!` 组合；
2. **`std::integral_constant`**：把编译期常量包装成类型，提供 `value` 成员和向底层类型的转换；`std::true_type`/`std::false_type` 是其布尔特化，`std::bool_constant<B>` 是 C++17 简洁别名；
3. **`std::ratio`**：编译期有理数，自动约分；`ratio_add`/`ratio_multiply` 等元函数做编译期运算，零运行期开销；`std::chrono` 的时间单位底层基于 `std::ratio`。

选型口诀：**约束模板参数用概念；编译期传一个常量值用 `integral_constant`；编译期算分数用 `std::ratio`。**
